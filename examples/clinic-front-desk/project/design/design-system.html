The decisions made once, so every screen is built from the same pieces. Generated from design/design-tokens.json; change the tokens and regenerate. The sample markup is guidance for the shape of each component, not code to paste.

Typography

Book, treat and sign off visits at the front desk.

Body text uses the system font stack at 16px with a 1.55 line height. Headings use the same family. Use plain h1, h2, h3 and p elements and style them once, here.

Shape

Corner radius: 10px on buttons, fields and cards; modals use 1.5×. Spacing steps: 4, 8, 12, 16, 24, 40.

Buttons

Use whenOne primary button per view for the main action; secondary for alternatives; ghost for low-emphasis actions; danger for destructive actions.
Do not use whenDo not use a button to navigate (use a link) or put two primary buttons side by side.
<button class="btn btn-primary">Save</button>
<button class="btn btn-secondary">Cancel</button>
<button class="btn btn-ghost">Learn more</button>
<button class="btn btn-danger">Delete</button>

Form fields

Use whenEvery input has a visible label above it; show errors in words beside the field and keep what the user typed.
Do not use whenDo not use placeholder text instead of a label.
<label class="field">Name
  <input class="input">
</label>
<label class="field">Email
  <input class="input is-error">
  <span class="error">Enter a full email address.</span>
</label>

Badges

Use whenA short status or count next to a title (Open, Paid, 3 new).
Do not use whenDo not use badges for long text or as buttons.
DraftActiveOverdue
<span class="badge badge-primary">Active</span>

Listings

Use whenAny collection (contacts, invoices, tasks): a main title, one line of detail, an optional badge, and actions on the right.
Do not use whenDo not build a table for fewer than three columns of real data.
  • Thandi DlaminiCut and fade · Saturday 10:00
    Deposit paid
  • Sipho NkosiBeard trim · Saturday 11:00
    Awaiting deposit
<ul class="list">
  <li>
    <div><b>Title</b><small>Detail line</small></div>
    <span class="badge">Status</span>
  </li>
</ul>

Modal

Use whenA short, focused task that returns to the same screen (up to about five fields, or a confirmation).
Do not use whenDo not use a modal for long forms or content people may want to link to.
