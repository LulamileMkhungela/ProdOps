# Starter design system

This is an editable starting point, not a completed design. Replace or remove it if you already have a system.

## Named tokens
Use CSS variables such as `--color-primary`, `--color-background`, `--color-text`, `--color-surface`, `--color-muted`, `--color-border`, `--color-success` and `--radius`.

## Component classes to consider
- `.button-primary`: primary actions using `--color-primary`.
- `.card`: content containers using `--color-surface` and `--radius`.
- `.input`: labelled fields with visible focus.
- `.badge`: concise status labels; include text, not color alone.

These are proposed names, not implemented components. Document your own components and verify accessibility.
